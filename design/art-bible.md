## 第 1 节 · 视觉身份

**三个视觉关键词**
1. **冷金属 Cold Metal** — 深蓝黑钢（`#0A0F16` → `#131C26` → `#1F2B38` 三级钢面）、低饱和、硬边直角、机械咬合。
2. **霓虹脉冲 Neon Pulse** — 能量只属于"活着的系统"：炮口、弹道、护盾、警报用高饱和自发光表达。
3. **工业栅格 Industrial Grid** — 一切都有坐标。战场是可读的工程图纸，不是油画。

**一句话视觉主张**
> 一座在深蓝黑钢板（`#0A0F16`）上用霓虹光（`#35E0FF`）运行的防御工程 —— 冷、硬、精确，每次开火都是系统的一次脉冲。

**参考氛围**：深夜军事指挥舱压上雨后工业港区的俯视监控画面 —— 主光只来自屏幕与指示灯，环境近乎无光；地面有微弱反射（低透明度斜条模拟，不用模糊）；信息密度高但秩序井然。能量一律"发光细线 + 双层光晕"，**光必须有边界和方向**，禁止大面积柔和光斑。敌我对比：我方设施边缘绝对平整、对称；敌人形状更有机、边缘更毛糙。

## 第 3 节 · 形状语言（Canvas 可绘制）

**基准**：建造格 40×40；塔体绘制区 36×36（格内居中，四周 2px 留白）；描边取整数 px，坐标对齐 0.5px 防模糊。

### 3.1 四塔几何

| 塔 | 底座 | 顶部构成 | 朝向 |
|---|---|---|---|
| A | 正方形 30×30，`#1F2B38` + `#FF9E42` 2px 描边 | 圆 r=9 + 内圆 r=5（`#0A0F16`）+ 炮管矩形 6×18 | 炮管随目标旋转 |
| B | 正六边形 R=17 | 中心圆 r=7 + 3 个 r=4 于 120° 距 11px | 不旋转；管口画成 **8×5 压扁椭圆**（俯角暗示）+ 下沿 3px `#0A0F16` 阴影弧 |
| C | 正八边形 R=16 | 同心圆 r=10 / r=6 各 2px 描边 + 中心 3×3 方块 | 环 25°/s 慢自转（纯装饰） |
| D | 正三角 R=18（尖端朝场中央） | 矩形 4×20 + 顶三角 4×6 组成垂直棱柱 | 棱柱绕中心旋转指向目标 |

**B 的"不可对空"必须可读**：除炮管下俯外，**仅 B 塔**在建造栏卡片与详情面板显示 10×10 对地角标（向下实心箭头 + 下方 2px 短横线，`#FFC53D`）。对空塔无角标。

**塔射程圈**：仅悬停/选中/建造预览时绘制 —— 1px 实线 `#35E0FF` @ **α 0.45**（合成 `#227488`，对地面 **3.21:1**）+ 内部填充 α 0.06，**正圆**（高台 `RNG×1.15` 同规格，不加粗）。

**C 塔是场域型**（范围内持续减速 −25/35/45% + 每秒掉血，**无 DoT 叠加、不指向其它塔**）：视觉上不得出现"中毒液滴""连线到友方塔"任何语义；场域用射程圈内 **5 条同心淡弧**（`#5B8CFF` α 0.08，间距 8px）表达"持续降温"。
**本作无支援/增益塔** —— 4 塔全部自打伤害，因此全项目**不存在任何"塔与塔之间"的连线或指向性光环**，不需要为它保留视觉语言。

### 3.2 六敌造型与机制视觉

- **GRUNT**：实心三角边长 16px + 顶部 r=2 亮点；移动时上下浮动 ±1px。
- **BULWARK**：11×11 圆角矩形 + 顶部 4×8 亮条（装甲板）。
- **SPRINTER**：14×7 菱形 + 尾部 3px 拖影（`#6EE7A8` α 0.35，长 8px）。
- **WASP**：倒 V（两三角 7×10）+ 中心 r=2.5 圆；**地面投影椭圆 `#000000` α 0.35，随飞行进度 t 由 rx=10/ry=4 线性增至 rx=14/ry=5.5**（越近基地越低）。**封顶 rx 14**：本体半径 12px，投影再宽会被读成"变大/变近"而非"变低"。
- **WARDEN**：六边形 R=16 + 内部十字 2px。**光环 R=90**：1.5px `#F2D7C2` @ **α 0.55** **虚线**（dash 8/6，12°/s 慢转；合成 `#938A84`，对路面 **4.25:1**）；每 4.0s 治疗触发瞬间升 α 0.75、200ms 回落。**虚线是刻意的**：与玩家塔射程圈（实线）形成形状区分，避免误读为友方建筑。**填充只画 r=20→90 的环带、中心留空**（内缘 20px > 本体 R16，故**圆环不会把自己包在里面**）。WARDEN 不吃自己的光环，若画成完整闭合圆，玩家会以为它也吃 −40% 减伤，从而误判"该先打它却以为打不动"。光环随其移动，死亡即消失。
- **BOSS**（**地面单位**，移速 22px/s，非飞行，故不需要投影椭圆）：八边形 R=28，外光 `#FF3B47` 2px；内环 R=18 反向旋转；核心 3 个 r=3 白点。**尺寸下限（不可妥协）**：外接直径 ≥ 最大普通单位（BREAKER 32px）的 **1.7×** —— 现为 56px（1.75×）+ 脉冲环 68px；Boss 漏一只扣 5 点基地 HP，玩家必须一眼认出它比别的单位大一个量级。
  **损伤阶段用"内环断口数"编码（主编码，不依赖颜色）**：100–75% 完整环 `#FF3B47`；≤75% 断 1 口，`#FF7A3B`；≤50% 断 2 口，`#FFC53D`；≤25% 断 3 口，`#F2F6FA`。断口为 40° 弧缺口，三等分均布，**只增不减**。
  **召唤预告**：每次跨过 75/50/25% 阈值时，对应断口向外喷 8 粒子 + 1 个 R=20→40 环（`#F2D7C2`，320ms）—— 必须先于召唤物出现 ≥400ms，否则玩家会当成凭空刷怪。**预告期间 BOSS 照常移动、照常受击、不禁足**（若禁足，400ms×3 = 1.2s 免费输出窗口，会实质削弱 Boss 并破坏三图难度曲线）。
  **双 Boss 同屏（M3 W12）**：两体直径 56px ≈ 1.4 格，不吞格；但脉冲环从 R=34 降为 **R=30、α 0.15→0.10**，避免两环交叠成噪点。

### 3.3 基地 / 核心
底座 100×100 正方形（`#1F2B38` + `#35E0FF` 3px 描边，四角各 14×14 直角 L 形 `#2A3A4C`）；内层同心正八边形 R=32（`#131C26` + `#35E0FF` 1.5px）+ 中心圆 r=12 显示血量色。
血量环：八边形外接圆 R=40，3px 弧从 -90° 顺时针，`#35E0FF` → `#FFC53D`(≤50%) → `#FF3B47`(≤25%)；每降 10% HP 随机增 1 处 4×4 焦痕方块（`#0A0F16`，上限 8 处）。

| 类型 | 位置 | 造型差异 |

> **造型差异的许可，只能由真实规则差异来换取。** 这条是硬规则，务必守住。

> 中枢的价值由**射程圈当场证明**：悬停塔卡到中枢位时，射程圈自然同时盖住 A、B 两段路径。可在预览态额外高亮被覆盖的两段路径（仅预览、不改底座），但**绝不改点位造型**。

### 3.5 盲区视觉语言（M3 两段 240px / 180px，GDD §5.3 末 + 附录 A 第 10 条强制要求）

盲区 = 不落在任何点位射程内的路径段。**必须一眼看出"这里打不到"，若玩家当成 bug 则设计失效。**

| 要素 | 规格 |
|---|---|
| 路径填充 | 保持 `#1F2B38`，**不变暗**（变暗后与地面 `#131C26` 混淆，实测仅 1.11:1） |
| **斜纹（唯一主信号）** | 45° ↗ 斜纹：线宽 **4px**、间距 **14px**、`#FFC53D` @ **α 0.50**（合成 `#8F783A`，对路面 **3.36:1**）。这是唯一达到非文本 3:1 的线索，**α 不得低于 0.50** |
| 辅助线索 + 图标（叠加，不可单独依赖） | ① 移除正常段的 2px 亮边 `#2E4154`（其本身仅 1.37:1，只能当次要线索）② 该段地面栅格线断开不绘制 ③ 段两端各一道 12px 竖向 `#FFC53D` @ α 0.50 短刻度 ④ 段中点上方 16×16 三角警告 + 感叹号，`#FFC53D` @ α 0.35，**常驻不呼吸**（避免动效疲劳） |

## 第 4 节 · 特效与动效

### 4.1 特效总表｜**能否被 reducedMotion 关闭，不看"是不是特效"，看"该事件有没有持久载体"**：有则可关（漏怪→HP 数字与血条恒在；BOSS 出场/召唤→本体在场），无则这段视觉即唯一信号、不得关闭（资源不足：价格与卡面均无变化）
**缓动函数**（手写，不引库）：`easeOutQuad t(2-t)` / `easeOutCubic 1-(1-t)³` / `easeOutQuint 1-(1-t)⁵` / `easeOutExpo t=1?1:1-2^(-10t)` / `easeInOutSine -(cos(πt)-1)/2` / `easeOutBack`(c1=1.70158)。

| 特效 | 时长 | 粒子上限 | 颜色 | 缓动 / 结构 |
|---|---|---|---|---|
| 开火枪口闪光 | 90ms | 4 | 塔色 → `#FFFFFF` | easeOutQuad；r 6→1 收缩圆 + 沿炮管 12px 亮条 α 1→0 |
| 弹道拖尾 | 粒子寿命 120ms | ≤12/发 | 塔色 α 0.9→0 | 圆 r 3→1，线性衰减 |
| 命中火花 | 140ms | 6 | `#FFC53D` → 塔色 | easeOutCubic；6 个 2×2 方块飞散 10px |

### 4.2 性能红线（违者按 bug 处理）｜**本节每条约束都必须能被工程字面实现 —— 禁止"动效""效率""效果"这类跨域统称，必须指名具体对象。同一条也管实现层**：若存在统一入口函数（时长 clamp / 粒子计数 / 位移量 / "禁止"语义 / 音效 / 粒子发射 / 提示 / 横幅），**必须按通道拆分** —— 一个入口吞掉分通道规格，等于在实现里把本节的具名要求作废

1. **同屏粒子硬上限 600**，软上限 400；超出按"最旧优先淘汰"丢弃，不做队列阻塞。
2. 单次特效粒子上限 60（仅 BOSS 出场），其余 ≤12；单个敌人同帧最多贡献 12 粒子。
3. 粒子系统**对象池预分配 800**，运行期零 `new`／零数组增删，用 `alive` 标记复用。
4. **禁止每帧 `createLinearGradient` / `createRadialGradient`**：预建 ≤8 个渐变缓存按 key 复用；屏幕暗角用 4 个静态预建渐变。
5. **禁止逐帧 `ctx.shadowBlur`**（单次可达数 ms）：辉光一律"同色双层圆/环（外圈 r×1.6、α 0.15）+ `globalCompositeOperation='lighter'`"。
6. 禁止 `filter`、`globalAlpha` 嵌套 >2 层、逐帧 `save/restore` >8 次；文字每帧 `fillText` ≤40 次，静态文案（塔名、价格、ARM）预渲染到 1 个离屏 canvas。
7. 计时全部用**毫秒累加**，禁止帧计数（120Hz 屏会让 DPS 翻倍）；禁止逐个改各计时器。倍速拆**两个时钟**：`worldDt = rawDtMs × timeScale` → 敌人移动 / 塔冷却 / 弹道 / 粒子拖尾 / 减速 / DoT / Boss 脉冲环；`rawDtMs` 不缩放 → 波次横幅 1200ms、提示浮层、结算面板入场、"防线失守"大字、按钮过渡、**资源不足造价数字位移 250ms**（3× 下 1200ms 横幅只剩 400ms，而横幅是"这波是装甲墙还是空袭"的核心载体，读不完）。
8. **波间倒计时走第三套时钟、独立处理**：`if (timeScale > 0) gapMs += rawDtMs` —— **不乘 timeScale、暂停时不累加**。理由一：3× 会惩罚喜欢倍速的玩家（现实时间被压缩、奖励按剩余秒算）。理由二：暂停能冻结时钟 → 玩家"暂停刷满提前召唤奖励"（每波白送 40 金币），机制退化成纯收入而非决策。**理由三（勿"修"）：3× 下波间仍是 20 现实秒，这一段刻意不加速 —— 它是玩家的操作窗口（手要动、塔要建、要读预览条）。倍速压缩的是"看"，不该压缩"做"。所以"战斗飞快、波间不变快"是设计，不是 bug，任何人不得改回缩放。**

## 第 6 节 · 可访问性

### 6.1 等级：**Standard（标准级）**｜桌面单人塔防、操作简单（鼠标 + 4 快捷键），无需 Comprehensive 重映射；但信息密度高（血条 / 双路 / 盲区 / 光环 / 状态效果同屏）、单局 8–12 分钟，色盲与动效敏感人群损失显著，**必须 Standard 而非 Basic**。目标：WCAG 2.1 AA 对比度与文本要求 + 游戏特有色彩/动效条款。

### 6.2 七条强制要求（均可被代码检查）｜**A1–A7 全部必须满足。A3/A4 的实现必须走"可替换结构"：取色一律经 `palette.*` 查表，HUD 布局常量一律为可乘系数；不得硬编码字面量**

| # | 要求 | 可检查判据 |
|---|---|---|
| A1 | **色彩非唯一编码**：塔靠底座边数 4/6/8/3，敌靠形状 + 尺寸，BOSS 靠断口数 0/1/2/3，盲区靠斜纹 + 断栅格，WARDEN 光环靠虚线 | 代码存在几何分支且渲染路径不依赖颜色参数；四塔与盲区灰度截图可辨 |
| A2 | **对比度**：正文/数值 ≥4.5:1。非文本按**用法**分两档（**档由承载方式判、不由色值判** —— 同一个 `#FF3B47` 可同时属两档）：**地板型**（须被看见）→ **≥4.5:1 无上限**；**窗户型**（须可辨但不许抢）→ **∈[3.0, 4.5)** | **两步定档，顺序不可换**：① 该色是不是这条信息的**唯一可辨通道**？是 → 地板型。否 → ② 该信息有没有**持久载体**（长度/数字/本体恒在）？有 → 窗户型；无 → 地板型。三例验证（每例都已注背景 —— 本条规则自己也要守）：血条低值段 `#FF3B47`@`#1F2B38` 路径 **4.09** →①否（长度+数字）②有（血条恒在）→ **窗户型，PASS**；顶栏受损闪烁 `#FF3B47`@`#0F1720` 顶栏 **5.13** →①是（纯色告知，无第二通道）→ 地板型 PASS；资源不足造价数字 `#FF3B47`@`#16202C` 面板 **4.67** →①否（位移/静叉）②无（价格卡面均不变）→ 地板型 PASS。**禁止按色值一刀切**（会把血条判违规、逼着把地图警示调亮到 HUD 告警强度，抹掉"地图后退、HUD 抢眼"的层级）；**禁止写成单向"非文本 ≥3:1"**（既拦不住调亮锁定灰，又抹掉告警下限）。**对比度是一对颜色的属性**，断言必须连背景一起写：`#FF3B47` 在 `#16202C` 4.67、`#1F2B38` 4.09；`#5C6B7C` 3.01 / 2.63 —— **跨背景套用即假断言**。**上界的作用域**：只约束表达**状态**的元素（不论在地图还是 HUD —— 锁定灰 3.01、射程圈 3.21、盲区斜纹 3.36、WARDEN 光环 4.25、边缘光 4.29）；**不约束表达"选中 / 当前 / 可操作"的强调态**（当前倍速档 `#35E0FF` **10.38**、科技树可点节点 `#7DFFB2` **13.17** —— 二者都满足①②，若无本句会被上界误判违规，而它们恰恰是该抢眼的）。强调态靠**尺寸 / 不透明度 / 位置 / 下划线**分层，**且不得兼作告警**：一旦兼用，告警这张牌就没有更强的可打了 |
| A3 | **色盲模式**：3 档（关 / deuteranopia / tritanopia），仅替换强调色与危险色映射表，**不改几何**。**实现方式（硬性架构约束）**：所有取色必须经色板表查表（`PALETTE` / `palette` 任意大小写均可），**不得硬编码色值字面量**；三套色板为可替换数据，换表即生效 | 全局 grep 十六进制色值，除色板定义段外 **0 命中**；存在 `deuteranopia` / `tritanopia` 两个**具名色板键**，按键 `#FF3B47`→`#FF9E42`、`#7DFFB2`→`#5B8CFF` 查得到（别名如 `deuter` 可另存，但两个全名键不得缺）；换表后几何与底座边数不变。**判据不得绑死标识符字面、不得区分大小写**——重命名是合法实现，规格验的是"取色走表 + 换表即生效"这一行为，不是命名 |
| A4 | **字号下限**：任何文字 ≥12px，关键数值 ≥16px；UI 缩放 100/125/150%（仅缩放 HUD，不缩放战场）。**实现方式（硬性架构约束）**：HUD 布局常量必须为可乘系数（首版系数恒 1.0），**不得散成字面量** | 所有 `font` 像素值 ≥12；缩放改布局参数而非画布分辨率；战场栅格恒 40px 不受系数影响 |
